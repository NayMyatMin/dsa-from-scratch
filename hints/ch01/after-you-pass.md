# Chapter 1 — after you pass: where each of these goes next

Nothing here is needed to finish the chapter, and it assumes you have already solved all three.
It's here so the lineage of each problem is on hand when you want more of the same shape.

**485 Max Consecutive Ones** — the direct sequels are *Max Consecutive Ones II* (Medium) and
*Max Consecutive Ones III* (Medium), which turn a run-scan into a genuine sliding window by
letting you flip some zeros. II is already on your syllabus in Chapter 6. Same family:
*Consecutive Characters*, *Longer Contiguous Segments of Ones than Zeros*, and *Maximum Enemy
Forts That Can Be Captured*, all Easy.

**1295 Find Numbers with Even Number of Digits** — *Finding 3-Digit Even Numbers*, *Number of Even
and Odd Bits*, and *Find if Digit Game Can Be Won*, all Easy. All of them reward the same instinct
Tier 4 is trying to build: read the constraints, then ask whether the general algorithm is
actually needed.

**977 Squares of a Sorted Array** — *Merge Sorted Array* (Easy) and *Sort Transformed Array*
(Medium). Note that Merge Sorted Array is your Chapter 2 problem, which is not a coincidence: the
fill-from-the-back trick you work out here is the same trick that problem wants.
