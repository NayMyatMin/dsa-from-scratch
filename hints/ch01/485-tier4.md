# 485. Max Consecutive Ones — Tier 4 (full strategy)

Update `best` on every 1, not only when you hit a 0. Then the final run has already been counted
by the time the loop ends, and you need no fix-up after the loop. Solutions that only update on a
0 must repeat the comparison once more after the loop — correct, but strictly more code and the
place the bug usually is.

O(n) time, O(1) space, single pass.

When it's green, ask me about the `itertools.groupby` version. It's a genuine one-liner, it's
arguably the idiomatic Python, and it's *worse* here for a reason worth discussing.
