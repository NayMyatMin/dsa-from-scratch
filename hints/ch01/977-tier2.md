# 977. Squares of a Sorted Array — Tier 2 (observation)

The shape is a valley: it falls, reaches a minimum, then rises. Never anything more complicated —
that's forced by the input being sorted.

Which means the **largest** square is always at one of the two ends. Never in the middle. And once
you take that one, the same is true of what's left.
