# 1089. Duplicate Zeros — Tier 1 (nudge)

Take `[1, 0, 2, 3, 0, 4, 5, 0]` and turn it into `[1, 0, 0, 2, 3, 0, 0, 4]` by hand, in those same
eight boxes, filling them left to right as you go.

You get two boxes in before it goes wrong. Say exactly what went wrong — not "it breaks", but which
value you destroyed and what you still needed it for.
