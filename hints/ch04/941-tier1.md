# 941. Valid Mountain Array — Tier 1 (nudge)

The definition names an index `i` and fences it in: `0 < i < arr.length - 1`. For `[0, 3, 2, 1]`,
say which index that is. For `[0, 1, 2, 3]`, say which index it would have to be, then read the
fence again.

Now `[3, 5, 5]`. Name the one step that fails — not "it isn't a mountain", but the two positions
and the comparison between them — and say which clause of the definition it breaks.
