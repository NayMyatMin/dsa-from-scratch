# 283. Move Zeroes — Tier 1 (nudge)

Write out the answer for `[0, 1, 0, 3, 12]` by hand. Now, for each element still standing in it, put
two numbers side by side: the index it started at and the index it ended at. Do the same for
`[1, 0, 2, 0, 3]`. Read down the two columns and say what separates them on each row — not "it
moved left", but a number you could have been keeping as you walked from index 0.

Then name the positions no surviving element lands in. Say how many there are and what has to be
sitting in each one, and say both without looking at the input a second time.

Last, say what a correct answer does to `[0]` and to `[1, 2, 3]`. One of those has nothing to move
and the other has nothing to move anything past.
