# Hints — Chapter 1

**One tier at a time.** Every tier lives in its own file, so opening one cannot show you the next
— no matter how tall your terminal is or whether your editor renders Markdown. This page holds
links only; there is no hint text on it.

Read a tier, close it, go back to the code. If you read three tiers in a row you have read the
solution, and the problem is spent — you can't unsee it.

Before opening any tier, try this instead: state out loud what your code currently does on the
specific failing input from the test output. Roughly half of "I'm stuck" turns out to be a bug you
can see once you say it, not a missing idea.

The escalation is **nudge → observation → approach → full strategy**. Tier 4 hands over the
algorithm; treat opening it as spending the problem.
